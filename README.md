# SK PDF Compressor

By **Tech Solutions**. Compress any PDF to **500 KB, 1 MB, 2 MB, 5 MB or 10 MB** while keeping the best possible quality.

- **Lossless first.** If the file already fits the chosen size, you get 100% original quality.
- **Images only if needed.** Images are re-encoded from the highest quality downward, only as far as needed to fit.
- **Text, fonts, tables and signatures are never changed.** They stay vector-sharp.
- Works offline. Your files never leave your computer.

## Download
Go to the **Actions** tab, open the latest **Build** run and download **SK-PDF-Compressor-EXE**. Tagged builds are also published as Releases.

## Run from source
```
pip install -r requirements.txt
python app.py
```
